# 📚 Jejak Belajar & Ruang Tugas

Platform pelacak progres pembelajaran, manajemen tugas, dan pengatur fokus belajar berbasis Pomodoro dengan arsitektur modern offline-first.

## 🚀 Fitur Utama
- **Manajemen Tugas & Materi:** Pencatatan target belajar dengan skala prioritas dan kategori.
- **Sesi Fokus & Timer Pomodoro:** Mode fokus 25m, 15m kilat, dan 5m jeda dilengkapi efek lonceng Zen Web Audio API.
- **Daily Motivation Widget:** Mood booster harian dan pencatat streak konsistensi belajar.
- **Offline First:** Seluruh data tersimpan aman dan instan di local storage peramban.

## 🛠️ Tech Stack
- **Frontend:** React 19, TypeScript, Vite
- **Styling:** Tailwind CSS
- **Icons & Animation:** Lucide React, Canvas Confetti, Motion
- **Audio:** Native Web Audio API
